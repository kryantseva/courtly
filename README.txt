📌 Система управления спортивным центром Courtly

🎯 Цель проекта:

Создать цифровую платформу для автоматизации процессов в спортивном центре по игре в Падел. Система должна объединить клиентов, тренеров, администраторов и руководство в единую экосистему, упростить бронирование кортов, контроль оплат, ведение отчётности и взаимодействие между всеми участниками.

👥 Роли пользователей

1. Клиент
- Регистрация и личный кабинет
- Онлайн-бронирование кортов
- Оплата (онлайн, карта, наличные через администратора)
- Аренда инвентаря при бронировании
- Запрос тренировок с тренером
- Отзывы о занятиях и тренерах
- Просмотр информации о центре, ценах, расписании, тренерах
- Раздел FAQ (частые вопросы)
- История посещений, оплат и тренировок

Через Telegram-бот:
- Напоминания о тренировках
- Уведомления об изменениях/отменах
- Быстрое бронирование
- Запись на турниры и анонсы от тренеров
- Общение с администратором

2. Тренер
- Личный кабинет с расписанием тренировок
- Возможность редактировать информацию о себе
- Просмотр отчётов по тренировкам и текущей зарплате
- Установка дней/времени, когда тренировки не ведёт
- Отказ от тренировки с согласованием через администратора
- Публикация анонсов игр и турниров через Telegram-бот

3. Администратор
- Управление бронированиями (проверка статуса, внесение наличных оплат)
- Поддержка клиентов через встроенный чат (Telegram-бот)
- Ответы по скриптам и шаблонам
- Модерация отзывов
- Обработка возражений тренеров (переносы, отказы)
- Внесение информации о своей смене (работаю/не работаю), отправка на согласование старшему администратору

4. Старший администратор/Директор

- Просмотр и выгрузка отчётности (по тренерам, клиентам, бронированиям, финансам, загруженности кортов)
- Добавление/удаление и редактирование тренеров и администраторов
- Управление количеством кортов и инвентаря
- Обработка запросов от администраторов (смены, спорные ситуации)

💻 Техническая часть

- Фронтенд: React.js 
- Бэкенд: Django + Django REST Framework
- База данных: PostgreSQL
- Платежи: интеграция с ЮKassа
- Telegram-бот: Aiogram 
- Авторизация: JWT/OAuth2, разграничение доступа по ролям
